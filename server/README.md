# เซิร์ฟเวอร์แจ้งเตือน (push) ของเหมียวสมาธิ

ให้แอปเด้งแจ้งเตือนได้แม้ปิดแอปหรือล็อกจออยู่ (แบบเดียวกับ LINE)

## ทำไมต้องมีเซิร์ฟเวอร์
เว็บแอปตั้งเวลาแจ้งเตือนล่วงหน้าเองไม่ได้ พอปิดแอปแล้ว โค้ดในโทรศัพท์จะไม่ทำงาน ต้องมีเครื่องปลายทางคอยส่ง push ไปปลุก service worker ตามเวลา

ระบบนี้ทำงานแบบนี้:
1. แอปคำนวณรายการเตือน 7 วันข้างหน้า (นัดหมาย บิล เช็กอิน น้ำ ออกกำลังกาย)
2. แอป **เข้ารหัสข้อความในเครื่อง** แล้วส่งไปแค่ "เวลา" กับข้อความที่เข้ารหัสแล้ว
3. เซิร์ฟเวอร์นี้ (Cloudflare Worker) มี cron ทำงานทุกนาที ส่ง **Web Push มาตรฐาน (VAPID)** ไปยังบริการ push ของแต่ละเครื่อง:
   - Chrome หรือ Android ส่งผ่าน FCM
   - iPhone หรือ Safari ส่งผ่าน APNs
   - Firefox ส่งผ่าน Mozilla

   ทั้งหมดใช้ Web Push มาตรฐานตัวเดียวกัน จึงไม่ต้องสมัคร Firebase
4. service worker ในโทรศัพท์ถอดรหัสข้อความ เช็กว่าเรื่องนั้นยังไม่ได้ทำ แล้วค่อยเด้งแจ้งเตือน

ทุกครั้งที่แก้ข้อมูลในแอป แอปจะส่งรายการเตือนชุดใหม่ขึ้นไปแทนชุดเดิม เรื่องที่ทำเสร็จแล้วจึงไม่เด้ง

## ติดตั้ง (ฟรี ประมาณ 10 นาที)
ต้องมีบัญชี Cloudflare (ฟรี) และ Node.js 20 ขึ้นไป

```bash
cd server
npm install
npx wrangler login

# 1) สร้างฐานข้อมูล แล้วเอา database_id ที่ได้ไปใส่ใน wrangler.toml
npx wrangler d1 create meow-push
npm run db:init

# 2) สร้างกุญแจ VAPID (ทำครั้งเดียว เก็บกุญแจลับไว้ให้ดี)
npm run keys
npx wrangler secret put VAPID_PUBLIC_KEY     # วางค่า public key
npx wrangler secret put VAPID_PRIVATE_JWK    # วางค่า JSON ของ private key

# 3) แก้ ALLOWED_ORIGINS และ VAPID_SUBJECT ใน wrangler.toml ให้เป็นที่อยู่แอปกับอีเมลของคุณ
npm run deploy
```

deploy เสร็จจะได้ที่อยู่ประมาณ `https://meow-push.<ชื่อบัญชี>.workers.dev`
- **วิธีที่ 1:** ใส่ที่อยู่นี้ใน `js/push-config.js` (`PUSH_SERVER`) แล้ว push ขึ้น GitHub Pages
- **วิธีที่ 2:** พิมพ์ที่อยู่นี้ในแอปที่ ตั้งค่า › แจ้งเตือนแม้ปิดแอป

แล้วกด "เปิดแจ้งเตือนแม้ปิดแอป" → "อนุญาต" → "ส่งทดสอบผ่านเซิร์ฟเวอร์"

ถ้าเปลี่ยนกุญแจ VAPID ทุกเครื่องต้องกดเปิดแจ้งเตือนใหม่

## เซิร์ฟเวอร์เก็บอะไร
- **subs:** ที่อยู่ push ของแต่ละเครื่องกับกุญแจสาธารณะ (ไม่มีชื่อ ไม่มีอีเมล) และค่า hash ของ token ที่เครื่องใช้ยืนยันตัว
- **jobs:** เวลาที่ต้องเตือน กับข้อความที่ **เข้ารหัสด้วยกุญแจที่อยู่ในโทรศัพท์เท่านั้น** เซิร์ฟเวอร์อ่านไม่ได้
- **ลบข้อมูลให้เอง:**
  - กดปิดในแอป → ลบเครื่องนั้นกับรายการเตือนทั้งหมดทันที
  - บริการ push แจ้งว่าเครื่องหาย (404/410) → ลบ
  - ไม่ได้ติดต่อมา 60 วัน → ลบ
  - เตือนช้าเกิน 2 ชั่วโมง (เช่นเซิร์ฟเวอร์ล่ม) → ทิ้ง ไม่ส่งย้อนหลัง

## รับกดพระ (หน้าลูกค้าและหน้าร้าน)
เซิร์ฟเวอร์ตัวเดียวกันนี้เก็บรุ่นที่รับกดและคำขอของลูกค้าด้วย (`src/shop.js`, ตาราง `shop_batches` กับ `shop_orders`) ถ้าตั้งเซิร์ฟเวอร์แจ้งเตือนไว้แล้ว ทำเพิ่มแค่ 3 ขั้น

```bash
cd server
npm run db:init                          # สร้างตารางใหม่ (ตารางเดิมไม่หาย รันซ้ำได้)
npx wrangler secret put SHOP_ADMIN_KEY   # ตั้งรหัสร้าน ใช้รหัสยาวๆ เดายาก
npm run deploy
```

จากนั้น push โค้ดขึ้น GitHub Pages แล้วใช้งานได้ดังนี้
- **หน้าร้าน:** `https://<ชื่อ>.github.io/health-app/shop-admin.html` ใส่รหัสร้านที่ตั้งไว้ แล้วเพิ่มรุ่น
- **หน้าลูกค้า:** `https://<ชื่อ>.github.io/health-app/shop.html` กด "คัดลอกลิงก์" ในหน้าร้านแล้วส่งให้ลูกค้า

**แจ้งเตือนลูกค้า:** ใช้กุญแจ VAPID ชุดเดียวกับแจ้งเตือนของแอป จึงไม่ต้องตั้งอะไรเพิ่ม ลูกค้าที่กด "เปิดแจ้งเตือน" จะได้รับข้อความเมื่อร้านรับงานหรือไม่รับ และเมื่อบันทึกว่ากดได้หรือกดไม่ทัน (ตาราง `shop_push` เก็บที่อยู่ push ของเบราว์เซอร์ลูกค้าต่อคำขอ ถ้าบริการ push แจ้งว่าเครื่องหายไปจะลบออกเอง)

**เซิร์ฟเวอร์เก็บอะไร:** ชื่อและช่องทางติดต่อที่ลูกค้าพิมพ์เอง จำนวนองค์ ค่ากดที่เสนอ หมายเหตุ และสถานะ ลูกค้าดูได้เฉพาะคำขอของตัวเอง เพราะเบราว์เซอร์ลูกค้าเก็บรหัสของแต่ละคำขอไว้ เซิร์ฟเวอร์เก็บแค่ค่า hash ส่วนข้อมูลทั้งหมดเปิดดูได้จากหน้าร้านเท่านั้น และต้องใช้รหัสร้าน ระบบรับคำขอได้สูงสุด 2,000 รายการ ลบรายการเก่าได้จากหน้าร้าน

## ทดสอบ
`npm test` ที่โฟลเดอร์หลักของโปรเจกต์มีชุดทดสอบของเซิร์ฟเวอร์ (`tests/push-server.test.js`) ดังนี้:
- เข้ารหัสแล้วถอดรหัสแบบที่เบราว์เซอร์ทำ ได้ข้อความเดิม (aes128gcm)
- ตรวจลายเซ็น VAPID
- ลำดับ subscribe → ส่งรายการเตือนขึ้นไป → cron ส่งตามเวลา → ลบเครื่องที่หายไป
- รับกดพระ (`tests/shop-server.test.js`): ร้านเพิ่มรุ่น → ลูกค้าส่งคำขอได้คิว → ยกเลิกแล้วคิวขยับ → ร้านรับงานและบันทึกว่ากดได้ → ลูกค้าเห็นผล และได้แจ้งเตือนเมื่อสถานะเปลี่ยน

ใช้ SQLite จำลอง D1
