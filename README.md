# สุขภาพดี – แอพบันทึกสุขภาพประจำวัน

เว็บแอพ (PWA) ภาษาไทยสำหรับติดตามพฤติกรรมสุขภาพประจำวัน ติดตั้งลงหน้าจอมือถือได้และใช้งานแบบออฟไลน์ได้

## ฟีเจอร์

- **วันนี้** – บันทึกการดื่มน้ำ (เป้า 8 แก้ว), จำนวนก้าว (เป้า 8,000), ชั่วโมงการนอน (เป้า 8 ชม.), น้ำหนัก และอารมณ์
- **ประวัติ** – กราฟย้อนหลัง 7 วัน พร้อมตารางบันทึกรายวัน
- **โปรไฟล์** – คำนวณ BMI (เกณฑ์สำหรับคนเอเชีย) และ BMR (สูตร Mifflin-St Jeor)
- นับจำนวนวันติดต่อกันที่ดื่มน้ำครบเป้า 🔥
- ส่งออกข้อมูลเป็นไฟล์ JSON / ล้างข้อมูล
- รองรับโหมดมืด (dark mode)

ข้อมูลทั้งหมดเก็บไว้ใน `localStorage` ของเบราว์เซอร์ ไม่มีการส่งข้อมูลออกนอกเครื่อง

## วิธีรัน

ไม่ต้องติดตั้ง dependency ใดๆ

```bash
npm start          # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
npm test           # รันเทสต์ฟังก์ชันคำนวณ (ต้องใช้ Node 18 ขึ้นไป)
```

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าจอทั้ง 3 แท็บ |
| `style.css` | สไตล์ (รองรับมือถือเป็นหลัก + dark mode) |
| `js/health.js` | ฟังก์ชันคำนวณล้วนๆ (BMI, BMR, streak ฯลฯ) — มีเทสต์ |
| `js/app.js` | การแสดงผล การบันทึกข้อมูล และ event ต่างๆ |
| `sw.js`, `manifest.webmanifest` | ทำให้ติดตั้งเป็นแอพและใช้งานออฟไลน์ได้ |

> แอพนี้ใช้ติดตามพฤติกรรมสุขภาพเบื้องต้นเท่านั้น ไม่สามารถใช้แทนคำแนะนำของแพทย์ได้
