# สุขภาพดี – สมุดสุขภาพส่วนตัว

เว็บแอพ (PWA) ภาษาไทย ออกแบบให้ใช้บนมือถือเป็นหลัก สำหรับคนขี้ลืม: ทุกอย่างบันทึกได้ใน 1–2 แตะ มีแจ้งเตือนตามเวลาที่ตั้งเองและกดเลื่อนได้ บันทึกย้อนหลังได้ และไม่มีระบบสตรีคที่กดดัน

## ฟีเจอร์

1. **หน้าแรก** – แสดงรายการที่ยังไม่ได้ทำวันนี้ แตะทีละอัน ส่วนที่ทำแล้วจะย้ายไปอยู่ด้านล่าง
   กด ‹ › หรือแตะวันที่เพื่อบันทึกย้อนหลัง
2. **เช็กอินตอนเช้า** – 5 คำถาม แตะตอบข้อละครั้ง (ชั่วโมงนอน, คุณภาพการนอน, ความเมื่อยแต่ละส่วน, ความเครียด, พลังงาน)
   แล้วได้คะแนนความพร้อม 0–100 พร้อมคำแนะนำว่าวันนี้ควร **เล่นหนัก / เล่นเบา / พัก**
3. **ดื่มน้ำ** กดปุ่มเดียวต่อแก้ว และ **อารมณ์** แตะอีโมจิ ทุกการบันทึกกด "เลิกทำ" ได้
4. **คู่มือเครื่องเล่น** 8 เครื่อง: วิธีปรับเครื่อง ท่าที่ถูก ข้อผิดพลาดที่พบบ่อย กล้ามเนื้อที่ใช้
   บันทึกค่าที่ตั้งเอง (ตำแหน่งเบาะ น้ำหนัก โน้ต) และเตือนถ้าส่วนนั้นเมื่อยจากการเช็กอิน
5. **เช็กลิสต์เตรียมของไปยิม** – แก้ไขรายการได้ รีเซ็ตทุกวัน โผล่ในหน้าแรกเฉพาะวันเข้ายิมที่ตั้งไว้

### การแจ้งเตือน

- ตั้งเวลาเตือนเองได้ในหน้า **ตั้งค่า** (เช็กอิน, ดื่มน้ำ, อารมณ์, เตรียมของ) เปิด/ปิด/ลบ/เพิ่มได้
- เมื่อถึงเวลา จะมีการ์ดเตือนด้านบนพร้อมปุ่มทำเลย, **เลื่อน 10 นาที / 1 ชั่วโมง**, หรือข้ามครั้งนี้
- ถ้าเปิดสิทธิ์แจ้งเตือนของระบบ จะเด้งแจ้งเตือนขณะที่แอพพับอยู่เบื้องหลัง (Android มีปุ่ม "ดื่มแล้ว +1" และ "เลื่อน 10 นาที" ในแจ้งเตือน)
- ถ้าทำสิ่งนั้นไปแล้ว (เช่นดื่มน้ำหลังเวลาเตือน) จะไม่เตือนซ้ำ

**ข้อจำกัด:** เว็บแอพยังตั้งแจ้งเตือนล่วงหน้าให้เด้งตอนที่ปิดแอพไปแล้วไม่ได้ ถ้าปิดแอพ รายการที่ถึงเวลาจะรออยู่ทันทีที่เปิดแอพครั้งถัดไป
ถ้าต้องการให้เด้งแม้ปิดแอพ ต้องเพิ่มเซิร์ฟเวอร์ Web Push ในอนาคต บน iPhone ต้อง "เพิ่มไปยังหน้าจอโฮม" ก่อนจึงจะใช้แจ้งเตือนได้

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเครื่อง ส่งออก/นำเข้าเป็นไฟล์ JSON ได้ในหน้าตั้งค่า

## วิธีรัน

ไม่ต้องติดตั้ง dependency ใดๆ

```bash
npm start          # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
npm test           # รันเทสต์ (ต้องใช้ Node 18 ขึ้นไป)
```

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `style.css` | โครงหน้าจอและสไตล์ (มือถือเป็นหลัก + dark mode) |
| `js/health.js` | logic ล้วน: คะแนนความพร้อม, รายการของวัน, คำนวณการเตือน/เลื่อนเตือน — มีเทสต์ |
| `js/store.js` | โครงข้อมูล, ค่าเริ่มต้น, ย้ายข้อมูลจากเวอร์ชันแรก — มีเทสต์ |
| `js/data.js` | ข้อความ ตัวเลือก และเนื้อหาคู่มือเครื่องเล่น |
| `js/app.js` | การแสดงผล การบันทึก และตัวจับเวลาแจ้งเตือน |
| `sw.js` | ใช้งานออฟไลน์ และจัดการปุ่มในแจ้งเตือน |

> คำแนะนำในแอพเป็นเพียงแนวทางคร่าวๆ ไม่สามารถใช้แทนคำแนะนำของแพทย์หรือผู้ฝึกสอนได้
